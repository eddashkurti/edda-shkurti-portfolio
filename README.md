# Edda Shkurti — Portfolio

https://eddashkurti.vercel.app/

Personal portfolio for Edda Shkurti, a Computer Engineering student focused on data engineering, cloud platforms, and practical software.

The site is designed as a **signal console** rather than a conventional portfolio template: an editorial archive of systems, products, and experiments with a dark instrument-panel aesthetic, sharp type, orbit graphics, and a project grid built from real GitHub work.

## Featured work

- [TechPoint Data Platform](https://github.com/eddashkurti/TechPoint_Data_Platform) — observable ingestion, lineage, schema contracts, quarantine, and Streamlit operations.
- [PulseMetrics SaaS Analytics](https://github.com/eddashkurti/PulseMetrics_SaaS_Analytics) — revenue, churn, retention, customer health, DuckDB, SQL, Python, and Power BI.
- [Momente](https://github.com/eddashkurti/momente_app) — event photo sharing with React, S3, Lambda, DynamoDB, and CloudFront.
- [NovaCart Data Platform](https://github.com/eddashkurti/NovaCart_Data_Platform) — Azure and Databricks medallion architecture with Delta Lake and quality checks.
- [Data Quality Observatory](https://github.com/eddashkurti/Data-Quality-Observatory) — deterministic validation, profiling, quarantine, and run history.
- [Consulting Meeting Optimizer](https://github.com/eddashkurti/consulting-meeting-optimizer) — role-based tasks, meetings, workload, and team workflows.
- [CloudVision AI](https://github.com/eddashkurti/cloudvision-ai) — privacy-first browser image classification using TensorFlow.js.
- [TechPoint Business OS](https://github.com/eddashkurti/techpoint-business-os) — a private Laravel business system for inventory, sales, accounting, reporting, and auditability.

## Stack

React · TypeScript · Vite · CSS · GitHub Pages/static hosting compatible

## Design direction

The visual system uses a near-black canvas, warm paper panels, acid-lime interaction cues, orange metadata, monospaced labels, and an orbit/grid motif. It is intentionally built without a component library so the portfolio’s identity stays specific to Edda’s work.
